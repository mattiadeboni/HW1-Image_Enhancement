# HW1 – Image Enhancement

Classical image enhancement pipeline for images affected by low contrast and noise.
Compares a degraded baseline with linear contrast stretching, histogram equalization
(on the L channel in CIE-Lab), and bilateral denoising followed by stretching.

Author: Mattia De Boni (VR555453)

## Requirements

- Python 3.11
- numpy 2.4.6
- opencv-python 5.0.0.93
- scikit-image 0.26.0

Install with:

```bash
pip install numpy opencv-python scikit-image
```

## Data

The five original photographs are in `data/original/` (1.png to 5.png). They were taken
by the author with a smartphone and are released under CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/).
Image 1 is 576×1024 pixels; images 2 to 5 are 768×1024 pixels.

Each original serves as the reference for evaluating its synthetic degradation.
A clean reference may not be available in real-world scenarios.

## Running the pipeline

Run the commands from the repository root, in this order:

```bash
python src/images_degradation.py   # creates data/degraded/
python src/enhance.py              # creates results/baseline, stretch, equalize, denoise_stretch
python src/metrics.py              # creates results/metrics.csv and prints the summary
python src/figures.py              # creates figures/comparison_<n>.png
```

The complete run takes a few seconds on a standard laptop.

## Degradation parameters

Each original is degraded as `P_deg = trunc(clip(g * P + b + n, 0, 255))`, with
`n ~ N(0, σ²)` drawn independently per pixel and per channel.

| Parameter | Value |
|---|---|
| Gain g | 0.5 |
| Bias b | 30.0 |
| Noise σ | 8.0 |
| Seed | 42 + index of the image in the sorted list of filenames |

## Methods

- **baseline**: the degraded image, unchanged.
- **stretch**: min–max linear stretch applied per channel (B, G, R).
- **equalize**: `cv2.equalizeHist` on the L channel in CIE-Lab, then converted back to BGR.
- **denoise_stretch**: `cv2.bilateralFilter` (d = 9, σ_color = 50, σ_space = 9), then the per-channel stretch.

## Outputs

- `data/degraded/`: degraded inputs
- `results/<method>/`: enhanced images, one folder per method
- `results/metrics.csv`: PSNR, SSIM, MAE and MSE for every image and method, with the degraded input as the reference row
- `figures/comparison_<n>.png`: side-by-side panels (original, degraded, stretch, equalize, denoise_stretch)
